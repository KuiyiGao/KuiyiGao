### Research

- **MMSafeAware:** safety evaluation for image–text inputs. ACL 2025. [Paper](https://aclanthology.org/2025.acl-long.832/) · [Code](https://github.com/Jarviswang94/MMSafetyAwareness)
- **Chain-of-Jailbreak:** safety of image generation across multiple editing turns. Findings of ACL 2025. [Paper](https://aclanthology.org/2025.findings-acl.571/) · [Code](https://github.com/Jarviswang94/Chain-of-Jailbreak)

- **Runtime safety for agent skills:** runtime permission checks and structured evidence records. Ongoing research. [Code](https://github.com/KuiyiGao/OpenClaw-Skill-Hack)

### Projects

- [MemSlot](https://github.com/KuiyiGao/Distorted-OCR-Compression): learnable attention over frozen RoBERTa features, document rendering, and an OCR-to-text QA pipeline.
- [Movability segmentation](https://github.com/KuiyiGao/QuickMotionDetection): DeepLabV3 with a custom ASPP head and four classes derived from COCO-Stuff labels.
- [Poetry and image variation](https://kuiyigao.github.io/#poetry): analysis of CLIP-based variation scores for FLUX and Stable Diffusion images.
- [Text-KEN](https://kuiyigao.github.io/#text-ken): a numerical prototype using RBF kernels, spectral entropy, and embedding preprocessing.
